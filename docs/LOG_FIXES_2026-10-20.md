# Log-driven stability changes, 2026-10-20

## Changes

- Native submenu callbacks resolve the live adapter item, reject stale positions and disabled items, and no longer capture the parent menu list.
- Dock preference opening, reading and JSON parsing run on Dispatchers.IO. Reload and edit generations prevent stale startup publication while metadata merges preserve user edits.
- Unchanged local PMTiles sources keep their eight-entry directory cache. URI/size/mtime keys and the eight-source LRU still invalidate changed or evicted archives; remote sources retain the five-minute TTL.
- Slow PMTiles reads distinguish archive lookup, range reading, directory retrieval and decompression. Music cache timing separates reading, parsing, restoration, USB checks and grouping without dropping availability checks.
- On API 30 and older, the shared window policy applies the legacy fullscreen/navigation/immersive bits together with insets requests. Activity, dialog and native popup windows share this policy. Saved preferences are preserved.
