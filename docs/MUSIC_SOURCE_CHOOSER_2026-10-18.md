# Music control chooser

The large player retains its source-icon entry point. It opens a single flat dialog showing the current controlled player and whether music is detected. The automatic card describes the normal behavior: follow external music, otherwise show Vela Music. Manual player rows show icons and observed playback state. There are no nested Select, Select and play, Keep this source or inclusion submenus.

Manual selection explicitly turns automatic tracking off and persists that mode without starting or pausing music. Playback remains a separate action on the existing player controls. Choosing automatic tracking clears the manual selection lock and immediately reevaluates existing playback, without requiring a new playback event. Advanced per-source inclusion remains in settings. Notification-access help is shown when required, with a direct settings action. Radio startup choices use discovered sources and no hard-coded hardware-brand labels.

The dialog updates on source identity, playing state and source-list changes, not position ticks. Its collector is canceled on dismiss, and the player host dismisses it on release.
